VORTEX ACADEMY — primeira versão visual

Arquivos:
- index.html: estrutura das páginas e conteúdo inicial
- styles.css: identidade visual responsiva
- script.js: menu para celular e ano do rodapé

Esta é a primeira versão visual (frontend). Ainda não está conectada ao Supabase:
cadastro/login, catálogo dinâmico, sala de aula, progresso e certificados serão
implementados nas próximas etapas.

Para publicar gratuitamente, use um repositório GitHub e Cloudflare Pages.
Não coloque senhas, service_role keys ou outras chaves secretas neste projeto.
